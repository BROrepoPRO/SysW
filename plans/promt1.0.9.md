# Задание для SourceCraft `plans/promt1.0.9.md`

**!!!ВАЖНО: `.ycarules` имеет высший приоритет!!!**

## Цель

Следующая версия проекта SysW — **v1.0.9**: обкатка уже внедрённых процессов **основной
бизнес-логики** на реальных данных без разработки новых функций. Фокус — на проверке
реальных сценариев пользователя: заполнение шапки заказ-наряда, импорт входящих данных,
ручной и автоматический подбор работ/запчастей, взаимодействие с файлами модельных групп.
Вспомогательные процессы (логирование, экспорт VBA, CI/CD) не трогаем, если они не мешают.

## Список задач

1. **ПОДГОТОВКА РЕАЛЬНЫХ ДАННЫХ И СРЕДЫ:**

   - Проверить, что в книге `work.xlsm` активна последняя версия модулей и листы
     `main`, `spisok`, `models` находятся в актуальном состоянии.

2. **ОБКАТКА ОСНОВНОГО БИЗНЕС-ЦИКЛА:**
   - Совместно с пользователем выполнить контрольный проход по реальному заказ-наряду:
     - ввод номера заказа в `B4` → заполнение шапки `B5:B17`;
     - запуск кнопки «ИМПОРТ ВХ»  на реальном листе М!
     - проверка корректности переноса работ в `L:N` и запчастей в `X:AA`;
     - ручной подбор работ через `Btn_main_MANWRK` (или актуальный обработчик);
     - автоматический подбор через `Mod_AutoMatch` (если он внедрён).
   - Фиксировать любые отклонения: неверные маппинги, лишние/потерянные данные,
     ошибки `Nothing`, некорректные сообщения, долгие зависания.

3. **ИСПРАВЛЕНИЕ ОШИБОК ОСНОВНОЙ БИЗНЕС-ЛОГИКИ:**
   - Исправлять только те дефекты, которые непосредственно влияют на рабочие сценарии
     из п.2. Приоритет: критические (потеря/искажение данных) → высокие (неверный
     результат при реальных входных данных) → средние (неудобство, но без сбоев).
   - Каждое изменение согласовывать с пользователем: до правки — краткое предложение,
     после — подтверждение ([Z5], [U1]).
   - Не добавлять новые функции и не менять утверждённую логику без явного запроса ([G3]).


4. **ДОКУМЕНТАЦИЯ, ВЕРСИЯ, ЧИСТОТА, GIT:**
   - Обновить `docs/table.md`, `docs/ARCHITECTURE.md`, `docs/DEVELOPER.md`,
     `docs/CHANGELOG.md` ([U2], [G2]).
   - Поднять версию до **1.0.9** (`update_version.py`/`config.py`).
   - Очистить проект от мусора: временные файлы, `_temp_export/`, `_temp_import/`,
     резервные копии, неиспользуемые артефакты ([S7]).
   - Подготовить коммит/пуш на `dev`; после утверждения пользователем — слияние `dev→main`.
