Структура файла группы UAZ.xlsx:

    лист UAZ - работы группы, полный список работ группы

    лист UAZw - выбранные работы группы из общего списка работ группы, на данном листе записывается тождество входящих работ с работами группы которые хоть раз вступали в тождество в основной бизнес-логике

    лист z4 - полный список з/ч один для всех моделей и групп (т.к. содержит около 700000 позиций, нахождение в каждом файле группы        такого листа нерационально, разработать процедуру вызова из отдельного файла z4.xlsx)

    лист UAZz4 - выбранные з/ч группы из общего списка з/ч один для всех моделей и групп, на данном листе записывается тождество входящих з/ч с з/ч группы которые хоть раз вступали в тождество в основной бизнес-логике

ПРАВИЛА ЛОГИКИ ДЛЯ UAZz4 и UAZw:

    - одна входящая работа может быть равной нескольким выходящим работам
    - одна выходящая работа может быть равной нескольким входящим работам
            пример: 2 входящих работы и 4 выходящих работа
            пример: 1 входящих работы и 2 выходящих работа
    - запчасти аналогично
    - тождество считается незаконченным пока в столбце АГРЕГАТ не пропадет значение
    - после тождества всегда пустая строка
    - при импорте работ из UAZw в книгу work на лист main, в случае если одна и та же позиция работ будет повторяться в разных агрегатах или в пределах одного агрегата - ВСЕГДА одна позиция работ записывается только 1 раз!!!
