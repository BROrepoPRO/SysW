## Список задач


Устранить проблему (возможно была из-за синхронизации) отсутствия виртуального окруж питон при загрузке терминала в вскоде

Удалить все связанное с синхронизацией через  Synhing - синхронизация удалена в Synhing

Интегрировать в систему SysW следующие mcp-сервера для кодассистсоурскрафт:

        - File System
        MCP сервер от @modelcontextprotocol

        - Git Tools
        MCP сервер от @modelcontextprotocol

Провести анализ задач

На основе результатов анализа составить план интеграции обновлений в систему

Реализовать план исправления

Обновить версию проекта до 1.0.2

Обновить документацию

Проверить файловую чистоту системы

Коммит, пуш



## Примечания

- все изменения согласовывать перед реализацией (создавать план в `plans/` или устный запрос у юзера)
- отвечать — только на русском языке
- комментарии в коде — на русском языке
- строго соблюдать правила `.ycarules`
- при неоднозначности — переспрашивать, а не делать предположения
- использовать роли актуальные для задачи/подзадачи
- после завершения задачи проверка чистоты проекта от мусора
- после завершения всех задач - запрос у юзера и выполнение коммита и пуша
