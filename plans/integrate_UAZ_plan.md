# План интеграции группы UAZ в проект SysW

> Версия: 2.0
> Статус: Утверждён пользователем

## 1. Обзор задачи

Интеграция файла группы `UAZ.xlsm` в существующую архитектуру проекта SysW.
Файл находится в `base/models/UAZ.xlsm` и содержит 4 листа с данными работ и запчастей.

## 3. Бизнес-логика (последовательность действий пользователя)

```mermaid
flowchart TD
    A[1. Ввод номера ЗН в B4] --> B[2. Заполнение шапки B5:B17]
    B --> C[3. Импорт из report.xlsx\nлист (B4)&M\nвходящие работы L:N\nвходящие запчасти X:AA]
    C --> D[4. АВТО РАБ\nпоиск входящих работ\nв UAZw по J Наим-ние]
    D --> E{Все работы\nнайдены?}
    E -->|нет| F[Подсветить жёлтым\nне найденные]
    E -->|да| G[5. АВТО ЗЧ\nпоиск входящих запчастей\nв UAZz4 по J № кат.]
    G --> H{Все запчасти\nнайдены?}
    H -->|нет| I[Подсветить жёлтым\nне найденные]
    H -->|да| J[6. Сообщение\nЗН заполнен!]
    F --> K[Ручной подбор\nне найденных]
    I --> K
    K --> D
```

### Подробное описание шагов:

**Шаг 1:** Пользователь вводит номер ЗН в B4
**Шаг 2:** Автоматическое заполнение шапки B5:B17 из spisok и models (уже реализовано в `Mod_OrderHeader`)
**Шаг 3:** Импорт листа `{B4}M` из `report.xlsx`:
  - Входящие работы → main L:N (Наименование, Кол.оп., Всего)
  - Входящие запчасти → main X:AA (№ кат., Наименование, Кол-во, Всего)
  (уже реализовано в `Mod_Import`)
**Шаг 4 (АВТО РАБ):** Для каждой строки в L:N:
  - Ищем в UAZw.J (Наим-ние) совпадение с L (Наименование)
  - Если найдено: копируем B→E, C→F, D→G, G→H, I→I(агрегат), B13→I
  - J вычисляем по формуле
  - Если не найдено: подсветить строку жёлтым
**Шаг 5 (АВТО ЗЧ):** Для каждой строки в X:AA:
  - Ищем в UAZz4.J (№ кат.) совпадение с X (№ кат.)
  - Если найдено: копируем B→Q, C→R, G→T, F→U
  - V вычисляем по формуле
  - Если не найдено: подсветить строку жёлтым
**Шаг 6:** Если все строки найдены — сообщение "ЗН заполнен!"

## 4. Пошаговый план реализации

### Шаг 1: Константы агрегатов в Mod_Constants

**Файл:** `src/modules/Mod_Constants.bas`

**Изменения:**
1. Добавить 16 констант `AGG_*` (DIAG, TO, ENG, TRANS, CLUTCH, SUSP, CHASS, BRAKE, FUEL, COOL, HVAC, STEER, ELEC, EXH, BODY, OTHERS)
2. Добавить функцию `GetAggregateName(code)` для получения русского названия
3. Добавить 16 записей в `BuildEntryArray` для libname

### Шаг 2: Mod_ModelDB — поддержка .xlsm и чтение тождеств

**Файл:** `src/modules/Mod_ModelDB.bas`

**Изменения:**
1. Изменить `GetModelGroupFilePath` — проверять сначала `.xlsm`, потом `.xlsx`
2. Добавить типы `WorkIdentity` и `PartIdentity`:
   - WorkIdentity: OutArticle(B), OutName(C), NormHours(D), QtyZN(G), Aggregate(I), InName(J)
   - PartIdentity: OutArticle(B), OutName(C), QtyZN(G), Price(F), Aggregate(I), InCatNum(J), InName(K)
3. Добавить `GetWorkIdentities(groupName)` — чтение листа `{GroupName}w`
4. Добавить `GetPartIdentities(groupName)` — чтение листа `{GroupName}z4`

**Логика чтения тождеств:**
- Читать строки с 4-й до последней
- Пустая строка = разделитель между группами тождеств
- Если столбец I (Агрегат) пуст — строка пропускается (тождество незакончено или разделитель)
- Возвращать коллекцию записей

### Шаг 3: Mod_SheetButtons — реализация кнопок поиска

**Файл:** `src/modules/Mod_SheetButtons.bas`

**Изменения:**
1. Реализовать процедуры на основе `Mod_Search` из work26.xlsm:
   - `Btn_UAZ_SearchByArticle()` — фильтр по столбцу B (Артикул)
   - `Btn_UAZ_SearchByName()` — фильтр по столбцу C (Наименование)
   - `Btn_UAZ_ClearFilter()` — сброс фильтра
2. Поле ввода — ячейка C1 (как в work26)
3. Диапазон данных: A4:{lastCol}{lastRow}
4. Фильтр по столбцу 2 (B) для артикула, по столбцу 3 (C) для наименования

### Шаг 4: Mod_ButtonDispatcher — обработчики

**Файл:** `src/modules/Mod_ButtonDispatcher.bas`

**Изменения:**

   - `Btn_UAZ_Article_Click()` → `Mod_SheetButtons.Btn_UAZ_SearchByArticle`
   - `Btn_UAZ_Name_Click()` → `Mod_SheetButtons.Btn_UAZ_SearchByName`
   - `Btn_UAZ_Clear_Click()` → `Mod_SheetButtons.Btn_UAZ_ClearFilter`

### Шаг 5: Mod_AutoMatch — автоподбор работ и запчастей

**Новый файл:** `src/modules/Mod_AutoMatch.bas`

**Назначение:** Реализация кнопок АВТО РАБ и АВТО ЗЧ

**Структура:**
```vba
' Главные процедуры (вызываются из кнопок main):
Public Sub AutoMatchWorks()      ' АВТО РАБ
Public Sub AutoMatchParts()      ' АВТО ЗЧ

' Вспомогательные:
Private Function FindWorkMatch(inName As String, identities As Collection) As WorkIdentity
Private Function FindPartMatch(inCatNum As String, identities As Collection) As PartIdentity
Private Function GetGroupName() As String
Private Sub HighlightNotFound(rng As Range)
Private Function IsAllFound() As Boolean
```

**Логика AutoMatchWorks:**
1. Получить группу из B14
2. Открыть UAZ.xlsm через `Mod_ModelDB.OpenModelGroupFile`
3. Прочитать тождества через `GetWorkIdentities`
4. Для каждой строки в L:N (начиная с 4-й):
   - Если L пусто — пропустить
   - Искать в коллекции `InName` = L
   - Если найдено: заполнить E, F, G, H, I(из B13), вычислить J
   - Если не найдено: подсветить строку жёлтым, пометить "НЕ НАЙДЕНО"
5. Проверить `IsAllFound` — если да, сообщение "ЗН заполнен!"

**Логика AutoMatchParts:**
1. Аналогично, но для X:AA
2. Искать в UAZz4 по `InCatNum` = X
3. Если найдено: заполнить Q, R, T, U, вычислить V
4. Если не найдено: подсветить жёлтым

### Шаг 6: Mod_MainButtons — подключение автоподбора

## 6. Риски

| Риск | Вероятность | Митигация |
|------|------------|-----------|
| Размер листа z4 (684k строк) замедлит работу | Высокая | Использовать Autofilter; читать только UAZz4 (тождества), а не весь z4 |
| Путаница с номерами столбцов после удаления M,N в UAZw | Средняя | Чётко documented в плане; использовать именованные константы |
| Кнопки не перенастроятся (OnAction не обновится) | Средняя | Проверить вручную после перенастройки |
| Совпадение по наименованию может быть неточным | Средняя | Использовать `InStr` или `Like` для нечёткого поиска |
