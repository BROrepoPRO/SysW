## Задачи

### Задача 1 (Направление 1) — Продолжить обкатку системы на реальных данных

Провести полный прогон рабочего цикла на реальных данных и зафиксировать результат.

Шаги:

1. **Базовый прогон тестов** — `python scripts/run_tests.py` (COM-автоматизация Excel,
   `work.xlsm`), контроль: Total/Passed/Failed/Skipped, отсутствие FAIL, запись
   `logs/test_results.log`. При невозможности — использовать прямой диагностический прогон
   с автозакрытием диалогов.
2. **Бизнес-прогон на реальных данных** — `python scripts/run_p1_business_test.py`
   (сценарий: `ImportFromB2_UI` → `AutoMatchWorks` → `AutoMatchParts`), контроль отчёта
   `logs/p1_test_report.log`; код/данные пользователя не модифицируются.
3. **Проверка ключевых функций на фактических данных** — корректность подстановки модельных
   кодов в [`Mod_Import.bas`](src/modules/Mod_Import.bas), автоподбор работ/ЗЧ в
   [`Mod_AutoMatch.bas`](src/modules/Mod_AutoMatch.bas), заполнение шапки заказа в
   [`Mod_OrderHeader.bas`](src/modules/Mod_OrderHeader.bas), ручной подбор в
   [`Mod_PickWork.bas`](src/modules/Mod_PickWork.bas).
4. **Сверка данных** — после импорта проверить колонки `main` (L:N работы, X:AA ЗЧ)
   против исходного листа `{B4}M`/`report.xlsx`; подтвердить соответствие фактическим данным
   в `work.xlsm` и модельных книгах `base/models/*.xlsm`.
5. **Фиксация результата** — отразить итоги обкатки (что проверено, что требует доработки)

### Задача 2 (Направление 2) — Реализация задачи R-16 из ROADMAP §11

Расширить `scripts/run_tests.py` (текущая точка входа — функция `main()`, парсер статистики
по строкам `Total=...`):

- **`--module <pattern>`** — выборочный запуск/фильтрация результатов по тестовому модулю
  (фильтр по совпадению имени теста/группы в результатах, возвращаемых VBA-функцией
  `GetTestResults()`);
- **`--verbose`** — подробный вывод по каждому тесту (в дополнение к сводной статистике
  Total/Passed/Failed/Skipped из ячейки `Z1` листа `main`);
- **`--output <path>`** — каталог/путь для сохранения отчётов;
- **генерация отчётов JSON и HTML** — машинно-читаемый и человекочитаемый отчёт по результатам
  прогона (структура из разобранной статистики + построчные результаты тестов);
- сохранить обратную совместимость: без аргументов поведение идентично текущему (запуск
  `RunAllTests`, чтение `Z1`, `logs/test_results.log`, exit code 0/1).

Соответствие критериям готовности R-16 из `docs/ROADMAP.md` §3:
`run_tests.py --help` показывает все аргументы; отчёты сохраняются.

После этой задачи выполнить коммит.

## Ограничения

- Изменения в `scripts/run_tests.py` — только после анализа текущей структуры (`config`,
  `open_workbook_with_retry`, `write_excel_pid`, `main`) и сохранения обратной совместимости.
- Кодировка: Python-скрипты — UTF-8; VBA-файлы на диске — UTF-8 (без BOM), в Excel — CP1251
  (двухфазная кодировка, правило K1-K3).
- Перед изменением ключевых файлов Excel — всегда делать копию (правило `[U5]`).
- Изменение критических файлов подзадачи — одним запросом на все файлы (правило `[U4]`/`[E3]`).
- Не выдумывать данные сверх того, что есть в реальном коде/документации; ссылаться на
  фактические модули (`src/modules/*.bas`, `src/classes/*.cls`) и скрипты (`scripts/*.py`).
